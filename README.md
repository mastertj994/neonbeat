## ✨ Особенности проекта

* **Киберпанк-дизайн**: Темная тема (`#0b0f19`), кастомные неоновые градиенты, пульсирующие рамки и анимированные текстовые эффекты.
* **Интерактивный аудиоплеер**: Полное управление воспроизведением, прогресс-бар, регулировка громкости и поддержка скачивания треков.
* **Мультиязычность / Регионы**: Удобный выбор треков по странам (Россия, Узбекистан, Таджикистан) и музыкальным жанрам (Хип-хоп, Поп, Рок).
* **Интерактивные отзывы**: Блок гостевых комментариев с мгновенным добавлением отзывов.
* **Адаптивность**: Отлично оптимизирован как для десктопов, так и для мобильных устройств (с удобной нижней панелью навигации).

---

## 🛠️ Технологии

Проект построен на чистых и современных технологиях без тяжелых фреймворков:
* **HTML5 / CSS3** (с использованием кастомных `@keyframes` анимаций)
* **Tailwind CSS** (для быстрой стилизации и гибкой адаптивности)
* **JavaScript (Vanilla JS)** (для логики плеера, фильтрации треков и интерактивных элементов)
* **Font Awesome** (для иконок)
